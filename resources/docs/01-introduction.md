# معرفی

**Filament Persian** یک پکیج کامل و حرفه‌ای برای فارسی‌سازی Filament v5 است.

## چرا این پکیج؟

Filament یک فریم‌ورک عالی برای ساخت پنل مدیریت است، ولی به‌طور پیش‌فرض برای زبان فارسی چند کمبود اساسی دارد:

- تقویم میلادی است، نه شمسی
- راست‌چین ناقص یا ناموجود است
- اعداد لاتین نمایش داده می‌شوند
- اعتبارسنجی‌های ایرانی (کد ملی، شبا، ...) ندارد
- جستجوی فارسی (ی/ک عربی) کار نمی‌کند
- کامپوننت‌های بومی ایران ندارد

این پکیج همه این‌ها را حل می‌کند — یک‌جا، تمیز، حرفه‌ای.

## ویژگی‌های کلیدی

| ویژگی | توضیح |
|---|---|
| 📅 **تقویم جلالی** | انتخاب و نمایش تاریخ شمسی در فرم‌ها، جداول و فیلترها |
| 🔄 **تبدیل خودکار** | ذخیره در دیتابیس میلادی، نمایش شمسی |
| 🎨 **RTL کامل** | راست‌چین حرفه‌ای همه کامپوننت‌ها |
| 🔢 **اعداد فارسی** | نمایش خودکار اعداد با جداکننده و واحد پول |
| ✅ **اعتبارسنجی ایرانی** | کد ملی، موبایل، شبا، کد پستی |
| 🧩 **کامپوننت‌های آماده** | JalaliDatePicker، JalaliDateColumn و... |
| 🔍 **جستجوی فارسی** | ی/ک عربی و فارسی یکسان دیده می‌شوند |
| 🖼️ **صفحه پروفایل** | با آواتار، تغییر رمز، ویرایش اطلاعات |
| ⚙️ **تنظیمات پنل** | فونت، رنگ، اعداد، تقویم — همه از پنل |
| 🌐 **Command Palette** | با `Ctrl+K` جستجوی سریع |
| 📊 **ویجت و نمودار** | آمار و نمودار با محور جلالی |
| 📖 **مستندات داخلی** | همه مثال‌ها داخل پنل |

## سازگاری

- **PHP:** 8.2 یا بالاتر
- **Laravel:** 11، 12، 13
- **Filament:** 4 و 5
